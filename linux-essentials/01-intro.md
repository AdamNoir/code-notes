# Linux Essentials - 01 Introduccion

## ¿Que es?
* Linux es un Kernel basado en unix.
* Un kernel es el nucleo de una PC, el cual controla la comunicacion entre software y hardware.
* Linux normalmente se distribuye en distribuciones o distros.
* Linux es de codigo abierto.
	* Codigo abierto o Open Source es el concepto de mantener el codigo visible al publico y permitir la modificacion del mismo.
	* De las modificaciones del codigo nacen Forks de un programa.
	* La gente puede aportar funcionales al codigo original de Linux, pero este pasa por fuertes pruebas.
* Existen varios tipos de licencias de codigo abierto:
	1. Apache
	2. GNU General Public
	3. MIT

### Distribuciones
* Las distribuciones son un conjunto del Kernel y aplicaciones GNU para un proposito especifico.
* Hay muchos tipos de distribuciones y estas son desarrolladas por grandes compañias o por grupos de voluntarios.
* Cada distribucion suele tener una filosofia o un porque de su existencia.
* Suelen tener un ciclo de vida entre versiones.
	* Tienen lanzamientos constantes y se recomienda estar siempre en la ultima version.
	* Muchas veces se requiere instalar todo o en distribuciones mas modernas con unos cuantos comandos.
	* Es posible quedarse en una version vieja, pero los repositorios y parches de seguridad deben ser tratardos por el usuario.
* Las distribuciones suelen tener requerimientos minimos y recomendados.
	* La HCL o Hardware Compatibility List es una lista de Hardware probada para ser compatible, o a veces no, con una distro.
	* El ejemplo mas claro de esto son las tarjetas de Nvida o algunas antenas de Red.

### Sistemas Embedidos
* Los sistemas embedidos estan hechos para cumplir funciones especificas en vez de ser de proposito general como un PC.
* Linux al ser ampliamente modificable permite usarse facilmente para este tipo de sistemas.
* Robots, Raspery Pi, Servidores, Android, son solo algunos ejemplos.
 
### Apps Open Source
* El software de codigo abierto se lanza bajo una licencia que permite a los usuarios ver, estudiar, modificar y distribuir el codigo.
* El codigo abierto ha estado desde el inicio de la informatica, cuando se compartia codigo para aprender. Al rededor de los años 80 se fue dejando de lado por el software comercial.
* Muchos expertos lo recomiendan por:
	1. Seguridad
	2. Transparencia
	3. Escalabilidad
	4. Localizacion
	5. Asequibilidad.
